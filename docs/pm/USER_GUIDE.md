# Project Management — User Guide

## Administrator: set up once
1. **Roles** — Configuration → Roles. Give each role its PM rights and its data visibility: Own, Team (the people under them and the teams they lead) or All.
2. **People** — Configuration → Users: employee code, department, reporting manager, photo. PM → Team Hierarchy shows the result.
3. **Masters** — PM → Setup: statuses, priorities, task types, work locations, holidays, working days and hours. Flags decide behaviour: the status flagged *Completed* completes a task, *Pauses TAT* stops the clock, *Waiting for client* sends a verification.
4. **Products** — Setup → Products: modules, tasks, TAT, default assignee, dependencies, checklist, auto messages. A project copies this; later changes do not touch running projects.
5. **Clients** — PM → Clients: contacts, the primary contact, portal logins.
6. **Sending** — Setup → Sending Settings: SMTP, test recipients. Switch **Test mode** off only when real clients should receive messages.
7. **Templates** — PM → Templates: the text of every email and WhatsApp message, with dynamic keys.

## Manager
- **Dashboard** — what is delayed, who is overloaded, what waits for the client. Every number opens its list.
- **New project** — Projects → New project → pick the client and product → adjust people and TAT → Create.
- **Follow up** — a project page: Overview, Modules, Tasks, Board, Timeline, Calendar, Team, Files, Activity.
- **Move work** — reassign a task, a module or the project (a reason is always asked); Projects → Transfer work for leave or an exit.
- **Team Calendar** — who is onsite, offsite or at home, and what is due.
- **Sign-off** — when a module's tasks are complete: Request sign-off.
- **Reports** — on-time delivery per person, reassignments, overdue, TAT compliance, and more; Export Excel.

## Employee
- **My Work** — overdue, due today, this week. Open a task, tick the checklist, change the status.
- **Comment** — `@` mentions a colleague; Ctrl+V pastes a screenshot.
- **Plan My Day** — Daily Plan: what, where (Onsite / Offsite / WFH), how long; at the end of the day mark Done / Partial / Not done.
- **+ Task** — your own task, with or without a project.
- **Bell** — new tasks, mentions, due tomorrow, overdue. Notifications → My settings chooses In-app / Email / WhatsApp.

## Client
- Sign in with the login from the team. **Projects** shows progress and dates.
- **Verifications** — approve or reject what the team asks you to check (also possible from the email or WhatsApp message).
- **Tickets** — raise an issue, reply, rate it when it is closed.
- **Documents** — files shared with you and the sign-off records.
